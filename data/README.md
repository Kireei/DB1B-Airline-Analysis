# Data

Source: U.S. Department of Transportation, Bureau of Transportation Statistics (BTS), Airline Origin and Destination Survey (DB1B).

Project scope: 2024 Q1-Q4.

Main source tables:
- DB1BTicket
- DB1BMarket
- DB1BCoupon

Raw files are intentionally not committed because they are very large. Download the quarterly files from the official BTS TranStats DB1B source and store them locally under `data/raw/`.

The analysis repository should contain code, documentation, selected derived outputs, and charts—not the raw multi-gigabyte source files.
